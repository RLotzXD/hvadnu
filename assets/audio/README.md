# Audio Assets

Place sound effects here:

- `shutter.mp3` - Camera shutter sound
- `recording_start.mp3` - Microphone activation beep
- `recording_stop.mp3` - Microphone deactivation beep
- `magic_sparkle.mp3` - Processing magic sound
- `victory_fanfare.mp3` - Victory celebration sound
- `step_complete.mp3` - Challenge completion chime

Recommended specifications:
- Format: MP3 (for broad compatibility)
- Sample rate: 44.1kHz
- Duration: Under 2 seconds for feedback sounds
- Duration: 3-5 seconds for victory fanfare
