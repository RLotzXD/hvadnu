# Theme Assets

Place theme-specific images and graphics here:

- `dragon_border.png` - Dragon theme viewfinder border
- `space_border.png` - Space theme viewfinder border  
- `pirate_border.png` - Pirate theme viewfinder border
- `victory_dragon.png` - Dragon victory animation
- `victory_space.png` - Space victory animation
- `victory_pirate.png` - Pirate victory animation

Recommended specifications:
- Format: PNG with transparency
- Size: 1024x1024 for borders (will be scaled)
- Color: Match theme accent colors
